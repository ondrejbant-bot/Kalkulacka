📖 Podrobný postup řešení krok za krokem:

1. Mínus před závorkou

Znaménko mínus před závorkou otočí všechna znaménka uvnitř závorky na opačná. Odpovídá to násobení číslem -1.

-(a + b) = -a - b
-(a - b) = -a + b

2. Zlomky v algebraických výrazech

Při sčítání a odčítání zlomků převedeme členy na společného jmenovatele (nejmenší společný násobek):

1/2x + 1/3x = (3/6 + 2/6)x = 5/6x

3. Procenta a zápis „z celku“

Procenta vyjadřují setiny celku. Slovo „z“ znamená násobení:

15% z x = (15/100)·x = 0,15x = 3/20x
x + 20% = x + 0,2x = 1,2x

4. Postup řešení lineární rovnice

1. Odstranit zlomky (vynásobit společným jmenovatelem).
2. Roznásobit závorky.
3. Přenést neznámé doleva, čísla doprava.
4. Vydělit koeficientem u neznámé a provést zkoušku.
